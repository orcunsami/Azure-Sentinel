| 3.0.2       | 05-09-2026                     | Import now processes each alarm page as it is read and verifies that every page was imported before the run completes. The Synced tag is applied after the SOCRadar write is confirmed. Aligned the critical alarm rule's severity filter and alarm URL with the SOCRadar platform format. Incident severity write-back to SOCRadar is governed by SyncSeverity (on by default) and only ever raises a severity, never lowers it. Added optional IoC extraction and bookmark-relation enrichment for new incidents, with a retry on transient relation failures. All Azure Resource Manager and Log Analytics endpoints are resolved from template variables. Import keeps its run window in a storage account table deployed with the playbook, so a run resumes from where the previous one finished. Alarms imported in a closed state are tagged as already synced. New IncidentMode parameter on the Import playbook: AlertBacked writes alarms to SOCRadar_Alarms_CL and deploys a scheduled analytics rule and an automation rule that raise the incidents, so they are also listed in the Microsoft Defender portal; Sync resolves the alarm from the incident's URL entity and reads the SOCRadar severity from the alert description in that mode. |
