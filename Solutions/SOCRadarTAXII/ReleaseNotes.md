| 3.0.0       | 02-10-2026                     | Initial release. Imports STIX 2.1 threat intelligence indicators from a SOCRadar TAXII 2.1 server into Microsoft Sentinel using an Azure Function App, with cursor-based pagination and per-collection checkpoints in a storage account table so a run resumes from where the previous one finished. A run that cannot deliver indicators to Microsoft Sentinel leaves its checkpoint in place and reports PartialSuccess, and the audit table records how many indicators were delivered, rejected and left behind. A run that stops on its time budget while a collection is still catching up stays Success and says so in ErrorMessage. Includes a workbook for indicator statistics and ingestion health, two hunting queries, and an analytic rule that reports runs which did not finish cleanly. The workspace can be created (`DeployNewWorkspace`, default true) or reused, in the deployment resource group or another one (`WorkspaceResourceGroup`), and with `DeployNewWorkspace` false a missing workspace fails before any resource is created. |
