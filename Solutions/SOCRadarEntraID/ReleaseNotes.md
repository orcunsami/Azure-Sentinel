# Release Notes

| **Version** | **Date Modified (DD-MM-YYYY)** | **Change History** |
|-------------|--------------------------------|--------------------|
| 3.0.0       | 12-05-2026                     | Initial release of SOCRadar Entra ID Integration solution. Ships an Azure Function App (Python 3.11, Linux Consumption Y1) that polls SOCRadar's Dark Web Monitoring APIs (Botnet Data v2, PII Exposure v2, VIP Protection v2), looks up leaked employees in Microsoft Entra ID via Microsoft Graph, takes configurable remediation actions (revoke sessions, MFA re-registration, disable account, add to quarantine group, password reset, mark as compromised in Identity Protection), and writes audit data to Log Analytics via the DCR-based Logs Ingestion API. Supports monitoring multiple Entra ID tenants from a single deployment via a comma-separated `EntraIdTenantIds` parameter — each leaked credential is looked up across the configured tenants (first match wins) and the matched tenant is recorded on every record. Authentication is secretless via Workload Identity Federation (User-Assigned Managed Identity + Federated Identity Credential against a multi-tenant App Registration). Includes 4 workbooks for Botnet, PII Exposure, VIP Protection, and a combined operational dashboard, all with a tenant filter dropdown and tenant breakdown panel. |
