# Release Notes

| **Version** | **Date Modified (DD-MM-YYYY)** | **Change History** |
|-------------|--------------------------------|--------------------|
| 3.0.0       | 01-10-2026                     | Initial release of the SOCRadar Entra ID solution. A Function App (Python 3.11) reads SOCRadar Botnet Data, PII Exposure and VIP Protection, looks leaked employees up in Microsoft Entra ID through Microsoft Graph, takes the remediation actions you enable (revoke sessions, force MFA re-registration, disable account, quarantine group, password change, mark compromised) and writes audit data to Log Analytics through the Logs Ingestion API. Several Entra ID tenants can be monitored from one deployment (`EntraIdTenantIds`). Authentication is secretless: managed identity plus a federated credential on an App Registration that already holds admin consent. The playbook never changes an existing workspace, can fail before creating anything when the named workspace does not exist (`CreateWorkspace` false), supports a workspace in another resource group, and stages the Function App package from the deployment script. Includes four workbooks (Botnet, PII Exposure, VIP Protection, Combined). |
